# Deepfake Detection

A deep learning project that detects deepfake faces using two approaches: a custom CNN and a fine-tuned XceptionNet. Trained on the **140k Real and Fake Faces** dataset.

---

## Dataset

This project uses two datasets, both available on Kaggle:

### [140k Real and Fake Faces](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces)
Used for the main CNN and initial Xception training.

- 70,000 **real** faces from the [Flickr dataset](https://github.com/NVlabs/ffhq-dataset) collected by Nvidia
- 70,000 **fake** faces sampled from the 1 Million Fake Faces dataset generated by StyleGAN
- All images resized to 256×256px
- Pre-split into train, validation, and test sets — the download includes `train.csv`, `valid.csv`, and `test.csv`

| Split      | Images  |
|------------|---------|
| Train      | 100,000 |
| Validation | 20,000  |
| Test       | 20,000  |

### [1000 Videos Split](https://www.kaggle.com/datasets/nanduncs/1000-videos-split/data)
Used for the Xception fine-tuning stage.

- Pre-split into `train/` and `validation/` folders
- ~11,600 training images and ~2,400 validation images extracted from video deepfake content

---

## Models

### 1. Custom CNN
A lightweight 3-block convolutional network trained from scratch.

- ~3.7M parameters
- **Test Accuracy: 97.56%**

### 2. XceptionNet (Transfer Learning)
Xception pretrained on ImageNet with a custom classification head, fine-tuned in two stages.

- ~55M parameters total
- **Best Validation Accuracy: ~89.1%**
- Uses `GlobalAveragePooling2D` + BatchNorm + Dense head
- Fine-tuned with EarlyStopping and ModelCheckpoint

## Usage

### Running the Notebook

1. Clone or download this repository
2. Download the [140k Real and Fake Faces](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces) dataset and place it under `real_vs_fake/`
3. Download the [1000 Videos Split](https://www.kaggle.com/datasets/nanduncs/1000-videos-split/data) dataset and place it under `1000_videos/`
4. Update all path variables as described above
5. Run `deepfake-detection.ipynb` top to bottom

### Testing a Single Image

At the bottom of the notebook there is a `test_new_image()` function. Pass the path to any face image:

```python
test_new_image('path/to/your/image.jpg')
```

The model will output:
- `REAL` if confidence > 70%
- `FAKE` with the corresponding confidence score
